# Nexora Studio — CSS Group Assignment

A four-page responsive website concept for an imaginary independent digital studio.

## Pages
- `index.html` — landing page: hero, four feature cards, quote, CTA and footer.
- `about.html` — studio background and principles.
- `services.html` — service details.
- `contact.html` — contact details and a demonstration form.
- `styles.css` — shared stylesheet for every page.

## Technical choices
- Semantic HTML5 and vanilla CSS.
- Flexbox for layouts; CSS media queries for responsive behaviour.
- CSS-only mobile burger menu using a checkbox, label and CSS selectors.
- Roboto imported from Google Fonts.
- Responsive images using `picture`, `source`, `srcset` and `sizes`.
- No JavaScript and no CSS Grid.

Images are hosted by Unsplash and require an internet connection. The contact form is a front-end demo only; it does not send or store submissions.

## Test widths
Use browser developer tools to test at 375px, 768px and 1200px or wider. Check horizontal overflow, navigation, image sizing and readable text.

## Client design specifications
- Hero background: `#1f2937`
- Header navigation links: `#e5e7eb`, 18px
- Header logo text: `#f9faf8`, 24px
- CTA button background: `#3882f6`
- Quote background: `#e5e7eb`
- Quote text: `#1f2937`, 36px, weight 300 (Light), italic

Other typography, spacing and supporting colours are design choices for the first draft and can be discussed with the team.

## Suggested collaboration steps
1. Create a shared GitHub repository and upload these files.
2. Ask teammates to review the layout and assign improvements through issues.
3. Use branches for changes and review each other's work before merging.
4. Test each page at the required widths before submission.
